# 시작 화면 메인 메뉴 설계

## 목표

게임을 실행하면 Homescreen에서 공포 분위기의 `Preternatural` 제목과 지지직거리는 시각 연출을 계속 보여 준다. 제목 아래에는 사용자가 바로 선택할 수 있는 `방 만들기`, `방 참여` 버튼을 둔다. 각 버튼은 필요한 입력만 담은 작은 카드를 열고, 기존 UGS Session 로비 흐름으로 연결한다.

## 사용자 흐름

1. Homescreen 진입 시 어두운 배경 위 제목 `Preternatural`이 붉은빛 밝기·알파·가로 미세 흔들림으로 반복 연출된다.
2. 제목 아래에 `방 만들기`, `방 참여` 버튼을 항상 표시한다. 기존 별도 `멀티플레이` 열기 버튼은 제거한다.
3. `방 만들기`는 닉네임 입력과 `방 만들기` 확인 버튼이 있는 카드를 연다.
4. `방 참여`는 닉네임·방 코드 입력과 `방 참여` 확인 버튼이 있는 카드를 연다.
5. 카드를 닫으면 즉시 두 개의 메인 버튼으로 돌아간다. 방 생성 또는 참여에 성공하면 기존 로비(방 코드, 복사, 인원, 시작/나가기)를 그대로 표시한다.

## 구성

### `HomeTitleSequence`

Homescreen에만 존재하는 코드 생성 Canvas로 제목과 어두운 배경을 계속 소유한다.

- 기존 2.5초 뒤 제거되는 인트로 오버레이를 지속적인 Homescreen 배경 연출로 바꾼다.
- `Time.unscaledDeltaTime` 기준의 결정적 반복 패턴으로 알파·색상·가로 위치를 갱신한다. 무작위 시드는 쓰지 않는다.
- 입력을 가로채지 않는 Canvas이며 `MultiplayerMenu`보다 뒤의 sorting order를 유지한다.
- Homescreen을 떠나면 Canvas를 제거하고 다시 돌아오면 처음부터 재생한다.

### `MultiplayerMenu`

기존 `NetBootstrap`에 붙은 코드 생성 uGUI 메뉴를 메인 메뉴 표면으로 재배치한다.

- 시작 상태에서 두 개의 메인 버튼만 표시하며, 별도 토글 버튼은 만들지 않는다.
- 두 입력 카드는 같은 Canvas에서 상호 배타적으로 표시한다. 카드 안에는 `뒤로` 버튼을 둔다.
- 생성·참여 요청, 로딩 상태, 오류 문구, 서비스 준비 상태, 로비 표시와 버튼 핸들러는 기존 `SessionManager` 경계를 그대로 사용한다.
- 로비·게임 씬 전환·세션 종료 후 Homescreen 복귀의 기존 동작을 보존한다.

## 안전성 및 제외 범위

- Session 생성/입장 API, Relay/NGO 시작 시점, 호스트 권한, 싱글플레이 시작 경로는 변경하지 않는다.
- 새 Scene YAML 또는 수동 버튼 배선은 추가하지 않는다.
- 이번 범위에는 사운드 파일 추가, 실제 노이즈 셰이더, 방 목록, 준비 시스템이 포함되지 않는다. 지지직은 TMP 텍스트의 시각 연출로 구현한다.

## 검증

1. EditMode에서 제목 반복 함수가 유효한 알파 범위와 루프 경계에서 동일한 결과를 내는지 검증한다.
2. EditMode에서 메인 메뉴 화면 상태가 초기 화면, 방 만들기 카드, 방 참여 카드, 로비 상태를 올바르게 선택하는지 검증한다.
3. Unity 컴파일 및 기존 EditMode 테스트를 실행한다.
4. Play Mode에서 Homescreen 첫 진입 시 제목, 두 버튼, 카드 전환, 로비 진입 후 기존 방 코드/시작 버튼을 확인한다.
