# 복도 정지 프리뷰 로비 설계

## 목표

게임 실행부터 방 생성·참여 후 로비 대기까지 Homescreen의 배경을 실제 `GameScene` 복도와 동일한 정지 프리뷰로 보여 준다. 기존 플레이어 카메라의 PSX 픽셀화·디더·인터레이싱 후처리 효과는 유지한다.

## 사용자 흐름

1. 게임을 켜면 Homescreen이 활성화되고, 실제 `GameScene`을 배경 전용으로 추가 로드한다.
2. 복도와 플레이어 카메라 화면 뒤에 기존 어두운 타이틀 연출, `Preternatural`, 방 만들기·방 참여·게임 종료 UI가 나타난다.
3. 방 만들기 또는 방 참여 입력 카드, 그리고 성공 후 로비 정보는 같은 정지 복도 위에서 표시된다.
4. 로비 호스트가 게임을 시작하면 기존 네트워크 흐름으로 `GameScene`을 단일 활성 씬으로 전환하고 정상 플레이를 시작한다.
5. Homescreen을 벗어나면 프리뷰 씬을 언로드하고, 다시 돌아오면 새로 준비한다.

## 구성

### `LobbyCorridorPreview`

Homescreen 전용의 지속 런타임 컴포넌트로, 프리뷰 씬의 로드와 정리를 소유한다.

- Homescreen이 활성 씬일 때만 `GameScene`을 additive로 로드한다. Homescreen은 계속 활성 씬으로 유지한다.
- 로드 완료 직후, `GameScene`의 기본 플레이어 카메라를 프리뷰 카메라로 유지한다. 카메라의 `PostProcessLayer`와 `PSXPostProcessEffect`는 켠 상태로 둔다.
- 기본 플레이어의 이동·마우스 룩·플래시라이트·상호작용과 게임 HUD를 비활성화한다. 이로써 입력이나 게임 진행으로 프리뷰 구도가 바뀌지 않는다.
- 프리뷰에서 동작하면 안 되는 몬스터·점프스케어·사망 등 게임 진행 MonoBehaviour도 비활성화한다. 프리뷰는 세계 상태나 네트워크 상태를 만들거나 복제하지 않는다.
- Homescreen의 기존 메인 카메라는 프리뷰 카메라가 준비된 동안만 비활성화해 이중 렌더링·오디오 리스너 충돌을 막고, 프리뷰가 해제되면 다시 원래 상태로 복구한다.
- 중복 로드, 빠른 씬 전환, 로드 중 Homescreen 이탈을 안전하게 처리하며, 프리뷰가 실패하면 기존 Homescreen 카메라와 메뉴가 계속 동작한다.

### 기존 UI

- `HomeTitleSequence`의 어두운 오버레이와 글리치 타이틀은 유지한다. 타이틀 Canvas는 프리뷰 카메라보다 앞에서 렌더링된다.
- `MultiplayerMenu`는 수정하지 않으며, 방 생성·입장·로비·게임 시작·종료의 기존 UI 상태 및 UGS Session 흐름을 보존한다.

## 제외 범위

- 복도 맵, 조명, 프리팹, PSX 셰이더, 게임 규칙, Relay/NGO 흐름을 변경하지 않는다.
- 새 복도 모델, 스크린샷 배경, 배경 음악, 카메라 이동 연출은 추가하지 않는다.
- 프리뷰에 실제 플레이어·몬스터·게임 HUD를 표시하거나 게임 상태를 동기화하지 않는다.

## 검증

1. EditMode에서 프리뷰 활성 조건과 Homescreen 이탈 시 정리 조건을 테스트한다.
2. Unity 컴파일 후 관련 Homescreen 및 로비 EditMode 테스트를 실행한다.
3. Play Mode에서 Homescreen에 복도·PSX 효과·메뉴가 함께 표시되고, WASD·마우스로 프리뷰가 움직이지 않는지 확인한다.
4. 방 생성/참여 UI 카드와 로비 UI가 같은 프리뷰 위에 유지되는지 확인한다.
5. 게임 시작 시 기존 `GameScene` 플레이가 정상으로 전환되는지 확인한다.
